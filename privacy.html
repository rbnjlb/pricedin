Privacy policy

Last updated: November 17, 2026

This policy covers two things: this website, and the Priced In publishing application ("the App"). The App is a private tool that the creator of the Priced In YouTube channel uses to publish and manage videos on that channel.

Who can use the App

The App is used only by the owner of the Priced In channel, for the Priced In channel. It is not offered to the public, and no other person signs in to it.

What the App accesses through Google

When the channel owner signs in with Google, the App asks for access to the YouTube Data API on the owner's own channel. With that access, the App can:

  • upload videos, and set their titles, descriptions, tags, thumbnails, publication dates and playlists;
  • read the channel's own videos, playlists and statistics, to check that a video was published correctly;
  • read the channel's own YouTube Analytics reports (views, watch time, audience retention, subscribers gained), to learn which videos work;
  • read the public comments posted on Priced In videos, and reply to them as the channel;
  • update the channel's own branding: description, keywords, banner and watermark.

Apart from the public comments posted on Priced In videos, the App reads no one else's data. It does not access Gmail, Drive, contacts or any other Google service.

How this data is used and stored

  • The data is used only to publish and manage the Priced In channel. Comments are read only to answer them.
  • The sign-in token is stored on the owner's private computers. It is never published or shared.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • No Google user data is used to train artificial intelligence or machine learning models.

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The App uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. The Google Privacy Policy also applies.

Revoking access

Access can be withdrawn at any time from the Google account security settings: myaccount.google.com/permissions. When access is withdrawn, the stored token stops working, and the owner deletes it.

This website

This website does not use cookies, analytics, trackers or forms, and it collects no personal data. It is hosted on GitHub Pages. GitHub may keep technical logs, such as IP addresses, under the GitHub Privacy Statement.

Contact

Questions about this policy: open an issue at github.com/rbnjlb/pricedin/issues.
